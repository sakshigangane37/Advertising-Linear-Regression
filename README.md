# Advertising Sales Prediction using Linear Regression - 

## Project Description

This project implements a Machine Learning application using the Linear Regression algorithm.

The project uses advertising expenditure data to predict sales based on different advertising options.

The dataset contains advertising information related to:

- TV
- Radio
- Newspaper

The `sales` feature represents the sales amount. :contentReference[oaicite:0]{index=0}

## Dataset

The dataset used in this project is:

`MarvellousAdvertising.csv`

### Features

- `TV` - Advertising expenditure on TV.
- `radio` - Advertising expenditure on radio.
- `newspaper` - Advertising expenditure on newspaper.

### Target

- `sales` - Sales amount.

## Machine Learning Algorithm

The project uses:

**Linear Regression**

The assignment specifically requires Linear Regression from the Scikit-learn library. :contentReference[oaicite:1]{index=1}
